# Playground

The AIX Playground is the official package lab for inspecting real `.aix` artifacts in the browser.

## What It Does

The playground lets you:

- upload a real `.aix` package
- inspect package entries
- read version and title metadata
- review page summaries
- inspect derived tool definitions
- preview individual files

## Why It Exists

The docs explain the format model. The playground verifies what that model looks like when a package is opened in a live browser surface.

This is why the playground is positioned as a lab rather than a generic demo.

## Runtime URL

The deployed runtime lives at:

- `/aix/playground/`

## Recommended Flow

1. read the [Format overview](/format)
2. understand the [Packages](/packages)
3. open the live playground
